# StudentStay SL

**StudentStay SL** is a multi-page website concept that helps students in Sierra Leone find, compare and enquire about accommodation in one place, with an initial focus on students around Limkokwing University.

> **Academic demonstration only.** All listings, prices and details are samples, not verified rental offers.

Built for the **DCOMP 204 Web Design Project** at Limkokwing University, Sierra Leone.

## The Problem

Finding student accommodation often means searching several sources, comparing prices and contacting property owners one by one. Students can struggle to compare room types, understand facilities and find options that fit their budgets.

## The Solution

StudentStay SL gathers accommodation information in one accessible place, with photos, locations, sample prices and room details.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero section, accommodation categories (single rooms, shared rooms, apartments) and a call to action |
| Accommodation | `accommodation.html` | Four sample listings with a location and room-type filter bar |
| Details | `details.html` | Single-listing view with price, facilities to confirm and an enquiry form |
| About | `about.html` | Project background, the problem, the proposed solution and target users |
| Contact | `contact.html` | Contact form and project information |

## Features

- Responsive layout for desktop, tablet and mobile
- Sticky navigation bar with an active-page highlight
- Listing cards for four room types: single room, shared room, self-contained and apartment
- Filter bar (location and room type) on the accommodation page
- Details page with an enquiry form
- Contact form with subject selection
- Shared footer with quick links, room types and project info
- Keyboard focus styles and reduced-motion support for accessibility

## Technologies Used

- **HTML5** for page structure
- **CSS3** (custom properties, Grid, Flexbox, media queries) for styling and responsive layout

## How to Run

No installation is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/jenebafambuleh10-sudo/Studentaccomodation_BIT1102_Jeneba_Fambuleh_905006231_Assignment1.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open the site in your browser.

If you use VS Code, you can also install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.

## Known Limitations

- The contact and enquiry forms are for demonstration. Messages are not sent to an email address or saved in a database.
- Listings are static sample content with sample rent figures.
- The filter bar, details page and form messages are built into the page markup but need JavaScript to work. A script file is not yet included in the project.
